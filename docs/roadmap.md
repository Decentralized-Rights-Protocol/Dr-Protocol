# DRP Verification Network Roadmap

## v0.1 — Foundation
- Canonical claim/evidence/proof objects
- Verification request API
- Policy engine
- Signed proof format
- Verifier and peer registries
- Local dev node
- CLI foundation

## v0.2 — Distributed verification
- Signed verifier identities
- Remote attestation exchange
- Verifier selection
- Quorum collection
- Challenge/dispute API
- Persistent storage
- Replay protection and request authentication

## v0.3 — Privacy
- Evidence commitments
- Selective disclosure
- Verifiable credentials
- Zero-knowledge proof integration
- Metadata minimization

## v0.4 — Network
- P2P transport
- Peer discovery
- Message propagation
- Node synchronization
- Rate limiting and abuse resistance

## v0.5 — Chain integration
- On-chain proof commitments
- verifier registration
- revocation state
- governance and dispute settlement

## v1.0 — Interoperable protocol
- Stable wire specification
- SDKs
- protocol version negotiation
- cryptographic agility
- independent implementations
- security audit
